# Variational Study of the Hydrogen Atom

This project applies the variational method to the hydrogen atom using a finite Gaussian basis set.

The generalized eigenvalue problem

\[
HC = ESC
\]

is solved numerically for increasing basis sizes in order to estimate the ground-state energy and wave function.

## Results

Using four Gaussian basis functions, the calculated ground-state energy is

**E₀ = -13.586064 eV**

compared with the exact value

**E₀ = -13.6057 eV**.
